# ATS Resume Analyzer

An AI-powered ATS Resume Analyzer that evaluates a resume against a given job description and provides an ATS compatibility score, skill matching, and resume improvement suggestions.

## Features

- Resume PDF/DOCX text extraction
- ATS compatibility score
- Keyword matching
- Technical skill matching
- Job relevance analysis
- Project relevance analysis
- Resume structure analysis
- Matched and missing skill identification
- AI-generated resume improvement suggestions
- Simple Streamlit-based interface

## Technologies Used

- Python
- Streamlit
- NLP
- LLM
- Pandas
- Scikit-learn
